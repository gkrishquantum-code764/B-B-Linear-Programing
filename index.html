SEE Optional Math — Linear Programming Definitions

1. Linear Programming

A mathematical technique of getting a maximum or minimum (or both) value of a linear objective function satisfying a given set of linear constraints is called linear programming.

2. Objective Function

A linear function whose maximum or minimum value is to be calculated is called an objective function.
Example: Z = 2x + 3y or P = 6x + 10y + 20.

3. Constraints

The conditions or restrictions in a linear programming problem which must be satisfied by the variables of the objective function are called constraints.
Example: 2x + y ≤ 14, x ≥ 0, y ≥ 0.

4. Feasible Region (Convex Polygonal Region)

A closed plane region bounded by the intersection of a finite number of boundary lines is called a feasible region. It is the common solution region satisfied by all given constraints.

5. Feasible Solution & System of Inequalities

A set of two or more inequalities in one or more variables is a system of inequalities. The values of variables $(x, y)$ that satisfy all the given constraints are called a feasible solution.
